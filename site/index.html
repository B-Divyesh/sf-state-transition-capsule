How it works

          
Capture only the state your bug changed.

          
Run files contain the state and events you declare. Review JSON on another machine, and redact sensitive fields before recording.

        

        
    
          
  1. 01
    Record
    Wrap the point where durable state changes. Set how many recent transitions each run file keeps.

  2. 02
    Redact
    Replace exact or wildcard paths before anything reaches the run file.

  3. 03

import { createRecorder } from "state-transition-capsule";

const run = createRecorder({
  name: "report / run 2",
  initialState,
  redact: ["auth.token", "**.password"],
  retention: { maxTransitions: 100 }
});

run.record(event, nextState);
